# 수용 기준 — hikage-navi v0.1

이 목록을 모두 통과하면 파일럿 개발을 끝낸다.  
그늘로 패리티는 기준이 아니다.

## A. 범위

- [ ] 서비스 카피가 시부야구·도보만이라고 적혀 있다.
- [ ] 시부야구 밖 두 점으로는 경로가 나오지 않고, 일본어 이유가 보인다.
- [ ] 직선 3 km 초과 요청은 거절된다.

## B. 그림자

- [ ] 주간 기본 시각에 시부야 건물 그림자가 지도에 보인다.
- [ ] 같은 날 10:00과 16:00을 비교하면 그림자 방향·길이가 눈에 띄게 다르다.
- [ ] 일몰 이후 시각에서는 그림자가 없고, 야간 안내가 보인다.

## C. 경로

고정 검증 점 (구현 후 실제 좌표로 확정해도 된다. 의도는 시부야역 일대 0.5–2 km):

- 출발: 시부야역 하치코 출구 부근
- 도착: 요요기공원 동쪽 입구 부근 **또는** 에비스역 부근 중, 구 안·3 km 이내인 점

통과 조건:

- [ ] 주간에 최단과 그늘 경로가 모두 나온다 (동일해도 된다).
- [ ] 각 경로에 거리(m), 시간(분), 그늘%가 있다.
- [ ] 그늘%는 0–100 정수이다.
- [ ] 최단 거리 ≤ 그늘 거리. (동일 허용)
- [ ] 지도에 두 선(또는 같은 길 한 선)이 출발·도착과 이어진다.
- [ ] 야간에는 최단만 나오고 그늘%는 비어 있다.
- [ ] 길에서 먼 곳(광장 한가운데 등)을 찍으면 스냅 실패 문안이 나온다.

## D. 조작

- [ ] 새로 연 뒤 탭 두 번으로 출발·도착을 넣을 수 있다.
- [ ] 시각을 바꾸면, 점이 있을 때 경로가 다시 계산된다.
- [ ] 새로고침하면 핀과 경로는 사라진다.
- [ ] 회원가입 화면이 없다.

## E. 출처·기술

- [ ] 화면에 국토지리원, PLATEAU, OpenStreetMap 출처가 있다.
- [ ] 공개 Nominatim/OSRM 데모 호스트를 호출하지 않는다.
- [ ] UI가 일본어다. (오류 문안 포함)

## F. 의도적으로 실패해야 하는 것

아래가 **되면** v0.1 범위를 넘은 것이다. 넣지 않는다.

- 창가 추천
