## 2. F1 지도 표시

- 초기 중심: 시부야역 부근 (약 139.7016, 35.6580), 줌 15.
- 배경: 국토지리원 표준지도 타일. API 키 없음. 출처 `国土地理院` 표시 필수.
- 시부야구 경계를 얇은 선으로 그려, 서비스 범위를 보이게 한다.
- 경계 밖도 지도는 움직이지만, 경로 탐색은 경계 안에서만 된다.
- 3D 기울기·회전은 하지 않는다. 2D 북쪽이 위.

## 3. F2 그림자 오버레이

- 선택한 시각이 **주간**(태양 고도 > 0°)일 때만 건물 그림자 폴리곤을 반투명하게 그린다.
- 그림자는 시부야구 건물(PLATEAU LOD1)만 사용한다. 가로수·지형은 무시한다.
- 건물은 수직 기둥으로 가정하고, 지붕 밑면을 태양 반대 방향으로 투영한다. 계산식은 [04-data-algorithm.md](04-data-algorithm.md).
- 야간에는 그림자 레이어를 그리지 않고, “夜間のため日陰を計算しません” 수준의 짧은 안내를 보여 준다.
- 시각이 바뀌면 기존 그림자를 지우고 새 시각으로 다시 그린다.
- 지도를 빠르게 움직일 때 매 프레임 재계산하지 않는다. 시각 변경·탐색 시에만 갱신한다. (팬/줌만으로는 그림자를 다시 계산하지 않음)

## 4. F3 시각 선택

- 기본값: 기기 로컬 시각. 타임존은 `Asia/Tokyo`.
- 사용자가 날짜와 시각(분 단위)을 바꿀 수 있다.
- 허용 범위: 선택한 날짜의 00:00–23:59. 과거·미래 모두 허용. 연도 제한은 두지 않되, 태양 위치 계산이 실패하면 오류로 처리한다.
- 시각을 바꾸면:
  1. 그림자 오버레이를 갱신한다.
  2. 이미 출발·도착이 있으면 경로를 **자동으로 다시** 계산한다.

## 5. F4 출발·도착 지정

### 5.1 지정 방법

- 지도에서 점을 고른다. 순서는 **출발 먼저, 도착 다음**.
- 출발이 있는 상태에서 지도를 다시 탭하면 도착을 덮어쓴다. 출발을 바꾸려면 “출발 다시 찍기” 동작을 쓴다. (화면 사양 참고)
- 브라우저가 위치를 허용하고, 좌표가 시부야구 안이면 “현재 위치를 출발로”를 쓸 수 있다.
- 현재 위치가 구 밖이면 출발로 넣지 않고, 구 안에서 찍어 달라는 메시지를 보여 준다.

### 5.2 스냅

- 탭한 좌표는 보행 네트워크의 **가장 가까운 노드**로 붙인다.
- 가장 가까운 노드가 탭 위치에서 **75 m를 넘으면** 그 점은 쓸 수 없다. “歩ける道の近くを選んでください”로 거절한다.

### 5.3 유효성

경로 버튼을 누르기 전에도, 점이 구 밖이면 핀은 찍히되 경고를 붙인다.  
탐색 시점에 한 점이라도 구 밖이면 F5에서 거절한다.

## 6. F5 경로 탐색

### 6.1 입력

| 필드 | 규칙 |
| --- | --- |
| origin | 시부야구 안, 보행 노드 75 m 이내 |
| destination | 동일. origin과 다른 노드 |
| datetime | Asia/Tokyo, F3에서 온 값 |

origin과 destination이 같은 노드이면 거절한다.

직선거리(하버사인)가 **3 km 초과**이면 거절한다.  
(“この距離は対象外です。3km以内で指定してください”)

### 6.2 출력 — 주간

두 경로를 한 번에 돌려준다.

| 경로 | 목적 | 실패 시 |
| --- | --- | --- |
| shortest | 보행 거리 최소 | 그래프 단절이면 전체 실패 |
| shadiest | 햇빛 구간 비용을 높인 경로 | 최단과 동일할 수 있음. 그 경우에도 두 개를 보여 주되 “同じルート”로 표시 |

각 경로에 넣는 값:

- 좌표열 (WGS84, 선)
- 거리 m (정수)
- 예상 시간 분 (보행 4.8 km/h, 올림)
- 그늘 비율 0–100 (정수, 반올림)
- 그늘 길이 m, 햇빛 길이 m

### 6.3 출력 — 야간

- shortest만 계산한다.
- shadiest는 `null`.
- 그늘 비율·그림자 오버레이는 제공하지 않는다.
- 거리는 계산하고, 그늘 지표는 “—” 로 보여 준다.

### 6.4 그늘 경로가 최단보다 너무 멀 때

그늘 경로 거리가 최단의 **1.5배를 넘으면**, 그늘 경로는 반환하되 경고를 붙인다.  
(“日陰ルートは最短より長いです”)  
자르거나 최단으로 바꾸지 않는다. 선택은 사용자에게 맡긴다.

### 6.5 그늘 비용 (요약)

엣지 가중치:

```
W = D_shade + α × D_sun
```

- `D_shade`, `D_sun`: 해당 엣지에서 그림자/햇빛에 해당하는 길이(m)
- v0.1의 `α = 3` (고정). 사용자가 바꾸지 못한다.

최단 경로는 `α = 1`과 같고, 사실상 거리만 쓴다.  
자세한 교차 방법은 [04-data-algorithm.md](04-data-algorithm.md).

### 6.6 오류

| 상황 | 사용자에게 |
| --- | --- |
| 구 밖 | 渋谷区内の2点を指定してください |
| 3 km 초과 | 3km以内で指定してください |
| 길에서 멈 | 歩ける道の近くを選んでください |
| 그래프 단절 | この2点を歩くルートが見つかりません |
| 서버/계산 실패 | しばらくしてからもう一度お試しください |

한 번에 하나의 오류만 보여 준다. 우선순위는 위 표 위→아래.

## 7. F6 경로 비교 표시

- 지도 위에 최단(한 색)과 그늘(다른 색)을 동시에 그린다. 겹치면 그늘 선을 위에 둔다.
- 카드에 두 경로의 거리 / 시간 / 그늘% 를 나란히 보여 준다.
- 기본 선택은 그늘 경로. 야간이거나 두 경로가 같으면 최단.
- 카드를 누르면 해당 경로가 강조되고, 다른 쪽은 얇아진다.
- 턴 목록(교차로 안내)은 없다. 선만 그린다.

## 8. F7 출처·범위 안내

화면 한곳에 고정:

- 地図: 国土地理院
- 建物: Project PLATEAU（国土交通省）
- 道路: © OpenStreetMap contributors
- 対象: 渋谷区 · 徒歩のみ

첫 방문 때 한 줄 소개를 보여 줄 수 있다. 닫으면 다시 자동으로 띄우지 않는다. (로컬 플래그)

## 9. 명시적 비기능 동작 (기능처럼 보이는 것)

- 회원가입, 쿠키 동의 배너, 광고 없음.
- 경로 히스토리를 서버에 저장하지 않는다. 새로고침하면 입력은 사라진다. (시각만 기본값으로 복귀)
- 오프라인 동작 없음.
