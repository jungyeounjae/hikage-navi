## 2. 태양 위치

- 라이브러리 자유. 결과는 위도·경도·UTC 시각에 대한 **고도(altitude), 방위(azimuth)** 와 같으면 된다.
- 좌표는 시부야 대표점(139.7016, 35.6580)을 써도 된다. 구 안에서 태양 위치 차이는 v0.1에서 무시한다.
- 고도 단위: 도. **고도 > 0** 이면 주간, **≤ 0** 이면 야간.
- 방위: 북 0°, 시계 방향. 구현 라이브러리가 다른 규약이면 투영 전에 이 규약으로 맞춘다.

## 3. 건물 그림자

가정:

1. 건물은 밑면과 같은 단면이 높이 `H`까지 올라가는 기둥이다.
2. 태양광은 평행광이다.
3. 지면은 수평이다. 경사·자기 그림자의 세밀한 면 가림은 v0.1에서 하지 않는다.

그림자 길이:

```
L = H / tan(altitude)
```

고도가 0에 가까우면 `L`이 매우 커진다. **고도 < 5°** 이면 `L`을  
`H / tan(5°)` 로 캡한다. (과도하게 긴 폴리곤 방지)

투영:

- 밑면의 각 꼭짓점을 태양 **반대** 방위로 `L`만큼 평행이동한 점을 지붕 투영으로 본다.
- 밑면 꼭짓점 ∪ 투영 꼭짓점의 볼록껍질을 그 건물 그림자로 해도 되고, 각 옆면 사다리꼴의 합집합을 써도 된다.
- 오목 건물에서 볼록껍질이 넓게 남는 것은 v0.1에서 허용한다.

결과: 시부야 전체 그림자 폴리곤의 합집합(겹침 병합은 선택).  
경로 교차에는 합집합이 아니어도 된다. 엣지와 각 건물 그림자를 쳐도 된다.

## 4. 엣지별 그늘 길이

각 보행 엣지 `e` (선분 또는 폴리라인):

1. `e`를 평면 좌표로 둔다.
2. 그림자 폴리곤과 교차하는 부분의 길이 합 = `D_shade`
3. `D_sun = max(0, length(e) - D_shade)`
4. `shade_pct(e) = D_shade / length(e)` (length=0이면 0)

야간에는 이 단계를 건너고, 그늘 지표를 계산하지 않는다.

## 5. 경로

그래프: 무방향 보행 그래프. 노드 = 교차·끝점, 엣지 = 보행 구간.

### 5.1 최단

```
W_short(e) = length(e)
```

다익스트라(또는 동등).

### 5.2 그늘

```
W_shade(e) = D_shade(e) + 3 × D_sun(e)
```

`α = 3` 고정.

의 의미: 햇빛 1 m는 그늘 3 m와 같은 비용.  
최단보다 최대 50%까지 돌아가며 햇빛을 피하는 정도의 성향이다. (하드 캡은 아니고 비용의 결과. 1.5배 초과 시 경고만)

최단·그늘 **모두** 같은 그림자 폴리곤으로 `shade_m` / `sun_m` / `shade_pct`를 채운다.  
가중치만 다르다. 야간에는 그늘 경로·그늘 지표를 계산하지 않는다.

### 5.3 스냅

입력 점 → 가장 가까운 그래프 노드. 75 m 초과 시 실패.  
거리 측정은 **하버사인(m)**. 시부야 규모·75 m 임계에서는 평면(EPSG:6677)과 실무상 동일하다.

### 5.4 시간·거리 표시

- 거리: 경로 엣지 길이 합, 미터 반올림.
- 시간: 거리 / 1.333… m/s (4.8 km/h), 분은 **올림**. 최소 1분. 0 m면 0분.
- 경로 그늘 비율: `sum(D_shade) / sum(length)` × 100, 정수 반올림.

## 6. 성능 목표

| 항목 | 목표 |
| --- | --- |
| 그림자 표시 | 시각 변경 후 5초 이내 |
| 경로 2개 | 요청 후 3초 이내 |
| 건물 수 | 시부야 LOD1 전량. 타일로 나누지 않아도 됨 |

목표를 못 지키면 **30분 단위 태양 버킷으로 그림자를 사전계산**하는 쪽으로 바꾼다.  
그 경우에도 외부 동작(F2, F5)은 같다. 시각은 가장 가까운 버킷에 붙인다.

## 7. 전처리 산출물 (구현 시 생성)

런타임이 읽을 파일만 고정한다. 포맷은 GeoJSON 또는 동등.

- `shibuya-boundary.geojson`
- `shibuya-buildings.geojson` (polygon + height)
- `shibuya-walk-graph` (노드·엣지. 구현이 정한 포맷)

원본 CityGML/PBF는 저장소에 올리지 않는다. 받는 방법만 나중에 스크립트로 적는다.
