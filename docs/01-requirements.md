# 요건 정의서 — hikage-navi v0.1

상태: 초안 (개발 착수 전)  
대상 지역: 일본 도쿄도 **시부야구(渋谷区)** 만  
작성 기준일: 2026-08-14

## 1. 한 줄 정의

시부야구 안에서, 선택한 시각의 건물 그림자를 보고, **같은 출발·도착에 대해 최단 도보 경로와 그늘이 더 많은 도보 경로를 비교**하는 웹 앱.

## 2. 배경과 목적

여름 낮 시부야는 보행 구간이 길고 고층 건물 그림자가 뚜렷합니다.  
한국의 그늘로는 도보·대중교통·버스 창가·가로수·산책 코스까지 다룹니다. 이 파일럿은 그 전체를 옮기지 않습니다.

이 버전에서 검증할 것은 세 가지뿐입니다.

1. 시부야 건물 높이로 시간대별 그림자를 그릴 수 있는가
2. 그 그림자를 보행 경로 비용에 넣을 수 있는가
3. 최단 길과 그늘 길을 한 화면에서 비교할 수 있는가

이 세 가지가 되면 v0.1은 성공입니다. 그 밖의 그늘로 기능은 이후 버전입니다.

## 3. 목표 사용자

- 시부야 일대를 낮에 걸어 이동하는 사람
- 관광·통근·환승 후 도보처럼, 10~30분 걷는 상황

로그인·프로필·맞춤 설정은 없습니다. 누구나 바로 씁니다.

## 4. 제품 원칙

1. **한 구만.** 시부야구 밖 출발·도착은 받지 않습니다.
2. **도보만.** 전철·버스·환승은 없습니다.
3. **건물 그늘만.** 가로수·공원·지하가는 계산에 넣지 않습니다.
4. **비교가 본체.** 그늘 길만 보여주지 않고, 최단 길과 나란히 보여 우회 대가를 알게 합니다.
5. **웹만.** iOS/Android 네이티브 앱은 이 버전 범위가 아닙니다.

## 5. 범위

### 5.1 한다 (Must)

| ID | 요건 | 설명 |
| --- | --- | --- |
| R1 | 시부야 지도 | 시부야구가 보이는 웹 지도. 배경은 국토지리원 지도. |
| R2 | 시각 선택 | 기본은 지금. 사용자가 날짜·시각을 바꿀 수 있다. |
| R3 | 건물 그림자 | 선택한 시각의 태양 위치로 건물 그림자를 지도에 그린다. |
| R4 | 출발·도착 | 지도 탭으로 출발과 도착을 찍는다. 현재 위치가 시부야 안이면 출발로 쓸 수 있다. |
| R5 | 두 경로 | 도보 **최단 경로**와 **그늘 경로**를 동시에 계산·표시한다. |
| R6 | 지표 | 각 경로의 거리, 예상 도보 시간, 그늘 비율(%)을 보여 준다. |
| R7 | 야간 | 태양이 진 시각에는 그림자와 그늘 경로를 계산하지 않고, 최단 경로만 보여 준다. |
| R8 | 범위 가드 | 출발 또는 도착이 시부야구 밖이면 경로를 만들지 않고 이유를 보여 준다. |

### 5.2 하지 않는다 (이 버전)

그늘로에 있으나 v0.1에 넣지 않는 것:

- 대중교통 경로, 실시간 도착, 약냉방칸
- 버스·지상 전철의 창가(좌우) 추천
- 가로수·수관·공원 그늘
- 지하도·지하가 우선
- 산책·러닝 순환 코스
- 경사·계단·혼잡도 필터
- 무더위쉼터·쿨스팟 경유
- 장소 키워드 검색(역명·주소 자동완성)
- 턴바이턴 음성 안내, 백그라운드 내비게이션
- 회원, 저장한 장소, 히스토리
- 시부야 밖·도쿄 전역
- 앱스토어/플레이스토어 배포

이후 버전에 열어 둘 후보는 `docs/02-functional-spec.md`의 백로그와 `docs/04-data-algorithm.md` §1.6(데이터 채택·보류)에만 적습니다. 구현 착수 조건이 아닙니다.

## 6. 사용자 시나리오

### U1. 낮에 그늘로 걷고 싶다

1. 지도를 연다. 지금 시각의 건물 그림자가 보인다.
2. 출발과 도착을 찍는다.
3. 최단 길과 그늘 길을 함께 본다.
4. 그늘 길이 몇 미터 멀고, 그늘 비율이 얼마나 높은지 보고 하나를 고른다.

### U2. 오후로 시각을 바꿔 본다

1. 시각을 15:00으로 바꾼다.
2. 그림자가 동쪽으로 길어진다.
3. 같은 출발·도착으로 다시 찾으면 그늘 경로가 달라질 수 있다.

### U3. 밤에는 최단만

1. 시각이 일몰 이후다.
2. 그림자 레이어는 꺼지고, 그늘 경로는 제공하지 않는다는 안내가 보인다.
3. 최단 도보 경로만 나온다.

## 7. 성공 기준 (사업·검증)

정량 KPI(다운로드 수 등)는 파일럿에서 두지 않습니다. 아래를 만족하면 v0.1 완료입니다.

- 시부야구 **안**의 서로 다른 두 지점(직선 0.5~2 km)에서, 낮 시각에 최단과 그늘 경로가 나오고 그늘 비율이 표시된다.
- 낮 시각을 바꾸면 그림자 모양이 바뀌고, 경우에 따라 그늘 경로도 바뀐다.
- 시부야 밖 점을 찍으면 경로가 나오지 않는다.
- 일몰 이후에는 그늘 경로를 만들지 않는다.

상세 판정은 [05-acceptance.md](05-acceptance.md)를 따릅니다.

## 8. 제약

| 항목 | 내용 |
| --- | --- |
| 언어 | 사양·개발 메모는 한국어. 앱 UI 문구는 일본어. |
| 라이선스 표기 | 국토지리원 타일, OpenStreetMap, PLATEAU 출처를 화면에 표시한다. |
| 외부 데모 서버 | 공개 Nominatim / 공개 OSRM 데모는 사용하지 않는다. |
| 거리 상한 | 도보 경로 요청은 **출발–도착 직선 3 km 이하**. 초과 시 거절. |
| 플랫폼 | 최신 Chrome / Safari 모바일·데스크톱. |

## 9. 용어

| 용어 | 의미 |
| --- | --- |
| 최단 경로 | 보행 네트워크에서 거리(미터)가 가장 짧은 길 |
| 그늘 경로 | 햇빛 구간을 비싸게 매긴 뒤 고른 길. 최단보다 길 수 있다 |
| 그늘 비율 | 경로 길이 중 건물 그림자 폴리곤과 겹치는 길이의 비율 |
| 시부야 범위 | 시부야구 행정경계 폴리곤 내부. 경계선 위는 안으로 본다 |
| 야간 | 해당 좌표·날짜에서 태양 고도 ≤ 0° |
