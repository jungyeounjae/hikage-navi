# 화면 사양서 — hikage-navi v0.1

앱은 **화면 하나**다. 지도가 바탕이고, 위에 패널이 겹친다.  
페이지를 나누지 않는다.

UI 문구는 일본어. 아래 일본어가 화면에 나가는 확정 문안이다.

## 1. 레이아웃

```
+--------------------------------------------------+
|  日陰ナビ          [日付] [時刻]                 |
|  渋谷区 · 徒歩                                    |
+--------------------------------------------------+
|                                                  |
|                   지  도                          |
|          (경계, 그림자, 핀, 경로)                 |
|                                                  |
|  [現在地を出発にする]                             |
+--------------------------------------------------+
|  출발/도착 상태 또는 경로 비교 카드               |
+--------------------------------------------------+
|  出典: 国土地理院 / PLATEAU / OSM                 |
+--------------------------------------------------+
```

모바일에서는 비교 카드가 하단 시트, 데스크톱에서는 좌측 또는 하단 패널.  
정보는 같고 배치만 좁은 화면에 맞춘다.

## 2. 상태 기계

```
S0 초기
  → 출발 핀 찍힘 → S1 출발만
  → 도착까지 찍힘 → S2 두 점 (탐색 전)
  → 탐색 성공(주간) → S3 비교
  → 탐색 성공(야간) → S4 최단만
  → 탐색 실패 → S5 오류 (점은 유지)
```

시각 변경은 어느 상태에서든 가능.  
S3/S4에서 시각이 바뀌면 같은 두 점으로 재탐색한다.

## 3. 상단 바

- 타이틀: `日陰ナビ`
- 보조: `渋谷区 · 徒歩`
- 날짜 입력, 시각 입력 (분까지)
- 야간이면 타이틀 옆에 `夜間` 표시

## 4. 지도 위 요소

| 요소 | 모양 | 조건 |
| --- | --- | --- |
| 구 경계 | 얇은 실선 | 항상 |
| 건물 그림자 | 반투명 어두운 면 | 주간만 |
| 출발 핀 | `出発` | S1 이후 |
| 도착 핀 | `到着` | S2 이후 |
| 최단 경로 | 실선, 한 색 | S3, S4 |
| 그늘 경로 | 실선, 다른 색, 최단 위에 | S3. 두 경로가 같으면 한 선 + `同じルート` |
| 현재지 버튼 | 지도 코너 | 항상. 권한 없으면 탭 시 브라우저 프롬프트 |

색 값은 구현 시 접근성(대비)만 지키면 된다. 최단과 그늘은 **범례로 구분**한다.

범례 문구:

- `最短`
- `日陰`

## 5. 하단 패널 문안

### S0

```
地図をタップして出発地点を選んでください
対象は渋谷区内の徒歩ルートです
```

### S1

```
出発が決まりました。次に到着地点をタップしてください
[出発をやり直す]
```

### S2

```
出発・到着が決まりました
[ルートを探す]  [やり直す]
```

`やり直す`는 두 핀을 지우고 S0으로.

### S3 (주간, 두 경로)

```
最短     1200m · 15分 · 日陰 20%
日陰     1350m · 17分 · 日陰 62%
日陰ルートは 150m 長いです
```

- 기본 강조: 日陰
- 그늘이 1.5배 초과면 한 줄 추가: `日陰ルートは最短よりかなり長いです`
- 동일 경로면: `同じルートです` 한 장만

### S4 (야간)

```
夜間のため日陰ルートはありません
最短  1200m · 15分
```

### S5

기능사양 6.6의 일본어 문안 한 줄 + `[閉じる]`  
닫아도 핀은 남는다.

## 6. 조작

| 조작 | 동작 |
| --- | --- |
| 지도 탭 (S0) | 출발 후보. 구 밖이면 경고만, 핀은 회색 |
| 지도 탭 (S1) | 도착 후보. 같은 규칙 |
| 지도 탭 (S2 이후) | 도착을 새 점으로 바꾸고, 경로는 지운 뒤 S2 |
| 출발을 やり直す | 전부 리셋 S0 |
| 現在地 | 구 안이면 출발 교체 후 S1 또는 도착이 있으면 S2 |
| 날짜/시각 | F3. S3/S4면 재탐색 |
| 경로 카드 탭 | 해당 선 강조 |

더블탭 줌은 지도 기본 동작을 따른다. 핀 지정과 충돌하지 않게, **핀 지정은 싱글 탭**만 쓴다.

## 7. 빈 화면·로딩

- 첫 로딩: 지도 타일이 뜰 때까지 중앙에 `読み込み中`
- 경로 계산 중: 버튼 비활성, `ルートを計算しています`
- 그림자 계산이 길면 지도는 먼저 두고, 그림자는 늦게 얹어도 된다. 경로 결과보다 그림자가 늦어도 된다. 단 경로의 그늘%는 계산이 끝난 값이어야 한다.

## 8. 접근·표시

- 최소 터치 영역 44 px.
- 색만으로 최단/그늘을 구분하지 않는다. 범례 라벨을 붙인다.
- 출처는 항상 보거나, 정보 버튼 한 번으로 본다. 없애지 않는다.
